# Medios de respaldo

Se incluyen tres capturas reales y una grabación WebM del recorrido público local, registradas el 4 de noviembre de 2026. Muestran programas, filtrado de nivel académico, comparación y becas. Se obtuvieron con frontend y catálogo reales, sin interceptar API, sin iniciar sesión y sin escribir en la base de datos. No muestran perfil ni recomendaciones autenticadas.

Agregar aquí únicamente pantallas y grabaciones reales, sin datos personales. Registrar las rutas y la fecha en `config/demo.ts`. Véase el README del pitch para un ejemplo. La guía de recorrido aparece si no hay medios disponibles y se identifica como guía; no simula pantallas reales.
